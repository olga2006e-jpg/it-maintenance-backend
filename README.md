# Логистика.Про — Frontend (ЛР №5)

## Запуск
npm install
npm run dev

## Страницы

### Лента (/feed)
- Полноэкранное видео (или placeholder.mp4)
- Название, описание (кнопка «Ещё» раскрывает полное описание)
- Кнопка «♥» — лайк (локально)
- Кнопка «↓» — следующее видео
- Метрики: скорость (км/ч), тариф (₽/км)

### Плитка (/catalog)
- Сетка карточек 2 колонки
- Фильтр-слайдер по тарифу (от/до) — поля `от` и `до`, кнопка «Поиск»
- Кнопка «Удалить» — удаляет карточку из локального стейта
- Клик по изображению → переход в ленту

### Добавление (/add)
- Заглушка, доступно только авторизованным

## Navbar (снизу)
- Лента , Транспорт — доступны (гость)
- Добавление, Вход — disabled

## Технологии
React 19, TypeScript, Vite, React-Bootstrap, React Router.
Без Redux и Context.
